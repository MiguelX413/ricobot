# Changelog

## v0.1.0

First version under the **RicoBot Next Generation** name. This version
establishes a new version series for the fork of Wei Mingzhi’s Ricobot.

- Set the CMake project version and Metamod plugin version to 0.1.0, and
  updated the in-game welcome message and project metadata.
- Retained the plugin filenames, existing configuration and console commands,
  and the 32-bit GoldSrc and Metamod interfaces.
- Baseline includes the fork’s CMake and CI migration, C++20 updates,
  capacity-checked file paths, RAII file ownership, and shared command
  validation.
- Added contributor credits, a third-party licensing audit, and a development
  roadmap. Documented the scope of the AGPL-3.0-only grant for original
  contributions.
